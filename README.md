# Drone AI Delivery SS2026

## Projektübersicht

Ziel dieses Projekts ist die Entwicklung einer KI-gestützten FPV-Drohne zur autonomen Objektauslieferung unter Verwendung von:

- ArduPilot
- Raspberry Pi Zero 2 WH
- Raspberry Pi AI Camera
- LiDAR (MTF-01P)
- Optical Flow
- GPS
