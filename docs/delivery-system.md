# Delivery System

## Ziel

Entwicklung eines Systems zur automatisierten Objektauslieferung.

## Geplante Komponenten

- Raspberry Pi Zero 2 WH
- Raspberry Pi AI Camera
- Micro Servo
- 3D-gedruckter Mechanismus

## Konzept

Die Drohne soll ein Objekt transportieren und an einer Zielposition automatisch freigeben.

## Diskutierte Ansätze

- QR-Code Erkennung
- KI-basierte Zielerkennung
- Automatische Auslösung des Servos

In Planung.
