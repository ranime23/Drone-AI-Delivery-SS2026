# Frame Design

## Ziel

Integration zusätzlicher Komponenten.

## Zu integrierende Komponenten

- LiDAR
- Optical Flow
- Raspberry Pi
- AI Camera
- Delivery Mechanismus

## Werkzeuge

- Tinkercad
- Ultimaker Cura
