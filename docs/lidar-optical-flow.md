# LiDAR und Optical Flow

## Ziel

Verbesserung der Navigation im Innenbereich.

## Sensor

MicroAir MTF-01P

## Funktionen

### LiDAR

- Abstandsmessung zum Boden
- Unterstützung von Altitude Hold

### Optical Flow

- Erkennung von Bewegungen relativ zum Boden
- Unterstützung von Position Hold

## Ergebnis

Die Sensoren ermöglichen stabile Flugmodi ohne GPS.
